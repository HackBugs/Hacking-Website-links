# 🖼️ Image & Photo Tools

Tools related to image editing, resizing, compression, background removal, perspective correction, cropping, etc.

### 1. ImageMagick GUI Suite
**Purpose:** ImageMagick ke CMD-based kaam ko GUI/graphical interface ke through use karne ke liye.

**Project:** `ImageMagickGUI_Suite`

```text
Unzip the project
pip install -r requirements.txt
Install ImageMagick on your machine if you haven't
python main.py
```
